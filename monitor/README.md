# Cloudflare monitor

The monitor checks usage, storage, delivery, and health and sends alerts through
your configured Telegram bot. Run setup and validation commands from the repository root.

- [English monitoring guide](../docs/en/monitoring.md)
- [Руководство по мониторингу на русском](../docs/ru/monitoring.md)
- [Main project README](../README.md)

Wrangler entrypoint: `service-entry.js`. `entry.js` implements the testable Cron handler.
